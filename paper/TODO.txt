[ ] 6.1 Key Findings and Trade-offs
    Points the results support:
    - LLM judges are at chance against provenance regardless of prompt;
      prompts change how often they say "AI", not whether they are right.
    - The judges agree with each other (kappa 0.67) more than with provenance,
      so they share surface heuristics.
    - A blind human beats every LLM run on the same files (0.65 vs 0.47-0.52),
      so some signal exists in the text and the LLMs miss it.
    - Classifier accuracy comes from format recognition, and accuracy against
      LLM labels (0.86-0.89 AUC) measures agreement with the judge.
    - Practical takeaway: do not use LLM judges as ground truth for
      AI-authorship studies; use provenance where it exists.

4. WHERE THE NUMBERS COME FROM
-----------------------------

- Provenance labels: data/labeled_data/provenance_evidence.csv
    PYTHONPATH=src python -m specmine.review
- Table 3 (classifiers + LLM judges, cross-validated):
    data/labeled_data/provenance_cv_results.csv
    PYTHONPATH=src python -m specmine.provenance_cv     (about 4 minutes)
- Tables 1 and 2 (LLM runs and human labels vs provenance): computed by
  comparing claude_labels1.csv, gemini_labels1-3.csv, informed_batch.csv
  and blind_batch.csv with provenance_evidence.csv. Score = confidence/100
  for label 1 and 1 - confidence/100 for label 0; bootstrap seeds fixed.
  These were run ad hoc and are not saved as a script yet.
